Breaking Down Buffer Overflows

2025-11-03  //  security

A buffer overflow occurs when a program writes more data to a buffer than it can hold, spilling into adjacent memory. It's one of the oldest classes of vulnerability and still shows up in the wild today.

The classic scenario: a fixed-size stack buffer, no bounds checking, user-controlled input. Write past the end of the buffer and you start overwriting the saved return address. Control that, and you control execution.

Modern mitigations — stack canaries, ASLR, NX/DEP — make exploitation harder but not impossible. Bypasses exist for all of them, and understanding why requires understanding the underlying mechanics.
