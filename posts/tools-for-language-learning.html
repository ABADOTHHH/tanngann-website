Tools for language learning

2026-05-12  //  language learning

The language learning community has been extremely prolific, comming with a myriad of software useful to language learners.

We are extremely fortunate to live in this time, I tell you ! Many thanks to all the people who have participated in fostering such a rich and convenient world for language learners.

HakuNeko : Download manager with various manga and anime sources preset.

Manatan : Complete media library with OCR for manga and anime.

Audacity : The forever humble and almighty audio editor ; I do all my audio capture and edits with this trusty software.


If you think of anything else that could be interesting to add here, please open an issue on Github.
