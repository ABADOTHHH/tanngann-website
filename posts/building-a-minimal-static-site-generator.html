Building a Minimal Static Site Generator

2025-07-10  //  dev

Static site generators are one of those tools where the existing options are all reasonable and building your own is entirely unnecessary. I built my own anyway.

The core is small: read Markdown files, apply an HTML template, write the output. A few hundred lines of Python. No dependencies beyond the standard library and a Markdown parser.

The benefit wasn't the tool itself — it was understanding exactly what the tool does, which means I can maintain and extend it without reading someone else's documentation. Sometimes the right abstraction is the one you wrote yourself.
